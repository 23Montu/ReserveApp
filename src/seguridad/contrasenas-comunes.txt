# Contraseñas comunes o previsibles que el registro rechaza (HU01, Issue #1).
#
# Alcance: selección manual de valores previsibles de al menos 15 caracteres: secuencias,
# repeticiones, patrones de teclado, frases conocidas y palabras propias del proyecto.
# NO cubre todas las contraseñas filtradas: no se comparó con ninguna base de datos de
# filtraciones y el sistema no consulta servicios externos.
#
# Mantenimiento: una contraseña por línea, sin espacios al inicio ni al final; las líneas
# que empiezan con # son comentarios. Se compara la contraseña completa, sin distinguir
# mayúsculas y unificando variantes Unicode (NFKC), así que basta una versión de cada valor.
# `npm test` falla si una entrada está repetida o no tiene entre 15 y 128 caracteres,
# porque esa entrada nunca podría coincidir con una contraseña aceptada por longitud.
